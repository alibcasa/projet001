# Engineering Rules

## Source of truth
GitHub is the source of truth for this project.

## Workflow
User Story
-> Acceptance Criteria
-> Implementation
-> Unit Tests
-> API Tests
-> E2E Tests
-> Security Checks
-> Pull Request
-> Review
-> Merge

## Git
- Never leave significant work only on the server.
- Work on branches.
- Commit meaningful changes.
- Push regularly to GitHub.
- Use Pull Requests for integration.

## Quality
A successful build alone does not mean Done.

Quality gates may include:
- unit tests
- API tests
- Playwright E2E
- Semgrep
- Trivy
- dependency audit
- code review
